| Component / Repository | Status | Scope |

## On-Chain Security & Tokenomics Guarantees

* **Primary Main Contract (BNB Smart Chain):** `0xaf8b1b1bb4a47f537932968C7DE6E251dd50C6a9`
* **Fixed Maximum Supply:** `200,000,000 CDBC` (No minting beyond fixed cap)
* **Tax Policy:** `0% Buy Tax / 0% Sell Tax`

## Contract Verification Rule

Always verify contract addresses against the official `Cloudbit-Global/core` repository and official portals (`https://cdbc.io` and `https://cloudbitex.com`). Never interact with unverified tokens or confund `CDBC` (Cloudbit Classic) with unrelated tickers.

## Reporting a Vulnerability

If you discover a potential security issue across our web portals, APIs, or ecosystem integrations, please report it directly via our official channels on `https://cdbc.io` or `https://x.com/cloudbit_` before disclosing it publicly.
